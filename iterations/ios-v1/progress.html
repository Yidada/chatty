验收记录

合成服务通过与真实业务通过分别记录。SDLC 当前阶段：Test。

ID 场景 状态 证据边界
A01环境隔离通过普通 Release 与 Fixture 分离；Simulator 与 iPhone 构建均通过隔离检查。
A02登录与认证错误通过验证码、当前与旧作用域 401、403/503、Keychain 持久化与清理。
A03Mika 与会话权限本地通过按 system_key 和授权范围识别；真实工作区仍待读取。
A04单次发送与未知回执通过两轮各一次 POST；非法回执保留待确认；不自动重发。
A05消息分页本地通过50→55、重复时间戳与消息 ID 去重；历史阅读保留位置。
A06任务过程与回复通过按 task_id/seq 关联、去重排序；失败说明、无回复和未知事件容错。
A07生命周期与隔离本地通过修正后台残留 Socket；后台 0 连接/0 新请求，恢复最多 1 条；离线草稿与未知回执重启保留。物理 iPhone 待验。
A08富文本与附件本地通过PhotosPicker 和 Files 合成样本上传、绑定、图片/Quick Look 读回；外域凭据、过期 URL 和限额测试通过。物理文件选择待验。
A09项目与 Issue 列表通过服务端 25/55 统计、50→55 分页、自定义筛选与无项目入口。
A10状态修改通过一次 PUT，suppress_run=true，expected_revision=1；冲突不重发。
A11协作资源本地通过Runtime、Agent、Squad 原生列表与详情回放通过。
A12原生可用性部分通过375×667 小屏、深浅色、两档辅助大字号、键盘和导航检查通过；最大字号需滚动，人工 VoiceOver 待验收。
A13存储与退出部分通过Keychain、排除备份、草稿/预览清理通过；物理文件保护属性待 iPhone。
A14真实 iPhone 业务闭环待条件目标 iPhone 仍 unavailable；待真实邮箱、Team 和明确测试消息。
