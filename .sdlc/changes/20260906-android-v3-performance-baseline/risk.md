# 风险：R3

消息缓存包含敏感业务内容，刷新优化影响身份与发送权限，因此整体采用 R3。

- 资产：账号凭据、工作区消息、草稿、权限与发送幂等语义。
- 主要风险：旧身份内容泄漏、权限撤销后仍可发送、重复发送、缓存损坏、请求风暴、内存增长。
- 控制：隔离 synthetic benchmark 包；真实用户数据不清理；身份分区与失效测试；不缓存权限作为永久授权；单独检验回执未知路径；对原始证据脱敏。
- 停止条件：跨账号显示、未授权写入、重复发送、无法解释的源版本差异，或设备被另一任务使用。停止对应实验并保留失败证据。
- 责任：Codex 执行与报告，用户 验收产品预算和缺失的具体设计决策；权限来源必须可追溯。
