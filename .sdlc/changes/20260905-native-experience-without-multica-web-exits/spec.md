# Specification
- R2：调整可见菜单与导航，数据协议、身份验证和持久化保持兼容。
- 设置首页仅显示工作区、切换/退出及 Runtimes、Agents、Squads 原生列表；资源详情仅显示已取得的事实字段。不提供未实现的配置入口。
- Issue 详情保留描述、状态修改、错误重读和关闭。
- 富内容保留可读文本/代码，不提供交互网页兜底。Markdown 指向 multica.ai（含子域、大小写、末尾点）或当前 API 主机的链接只呈现文字；浏览器出口复查同一策略。第三方资料链接仍可打开，附件的系统文件查看器保留。
- 消息内图片在原生弹窗查看和关闭；不使用浏览器放大。
- 无工作区时只呈现当前为空，并允许原有刷新/退出流程，不引导网页创建。
- 错误和空状态继续有原生反馈；无隐式 API 写入；状态修改继续 suppress_run=true。
## Acceptance mapping
1. 菜单/按钮删除 -> 真机遍历设置、资源详情、Issue 和富内容；源码出口扫描。
2. 链接策略 -> JVM 单测覆盖域名、相对路径、API、非法 scheme、第三方链接；合成 Markdown 点按检查停留应用。
3. 原生图片 -> 合成图片打开/关闭后仍在 Chatty。
4. 回归 -> 已有项目和聊天真机循环；构建、单测、lint。
