# 实现审查

## 结论
P1-P4 客户端实现及 P5 本地自动化、显示和生命周期检查已完成。真实账号与物理 iPhone 验收未完成，当前变更保留 Test 阶段，不进入完整产品验收完成状态。

本记录为同一实现者的自行审查，没有独立 reviewer。没有发现需阻止本地试用的已知代码缺陷；不据此承诺真实后端或物理设备已经通过。

## 已检查的边界
- 正常包的服务地址、源码组、依赖和 ATS；测试包的独立身份与目录。
- Email code、Keychain 失败处理、旧 401、logout marker 和受保护文件清理。
- 工作区不可变请求作用域、迟到回调、Socket generation、后台停止、REST 恢复与消息去重。
- 单次写入、先保存待确认再发送、合法回执、附件遗漏/部分绑定、不确定状态不自动重试。
- Issue 状态目录不可用、revision 冲突、明确 suppress_run、提交后刷新失败提示与当前 401 处理。
- 外域签名地址无凭据、禁止重定向、20 MB 下载/上传限制、文件名处理、Quick Look 清理与主动内容按文本呈现。
- 富文本仅原生渲染；内部资源原生路由；任务过程文字与输入 JSON 的常见凭据隐藏。
- 33 项 Swift 测试、4 项 iOS 系统测试通过；物理文件保护属性明确 skip。
- 三段设备回放共 117 步、0 自动修正；退出后受保护文件为 0，受控测试最多 1 条活跃 Socket。

## 实际发现与处理
1. 未签名 Simulator App 无法写 Keychain：改用本地 ad-hoc 签名，系统读写/可访问等级测试通过。
2. 容器标识覆盖子控件：为富文本与消息增加明确可访问性分组。
3. 回放动态 UIKit 祖先层级易变化：使用稳定 ID 与内容断言；为资源详情增加唯一标识，并分开测试会话。
4. 冷启动断网缺少草稿恢复：保存凭据哈希绑定的最少作用域元数据，提供仅编辑草稿的离线页。
5. 深色发送按钮前景对比不足：将强调色上的前景跟随深浅主题调整。
6. 照片先完整加载到内存再限额：改用 FileRepresentation，检查文件大小后读取。
7. 已读回执增加前台与页面可见限制，避免后台完成的响应标记新消息已读。
8. 实际后台测试发现优雅关闭保留旧 Socket：改用独立临时 URLSession 并立即取消传输；后台 0 连接/0 新请求，恢复和主动断线后最多 1 条连接。
9. 项目、Issue 和资源的可见页面增加前台自动刷新；服务端合成更新后原生项目页 25/55 自动变为 26/55。
