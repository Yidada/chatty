# Decisions

- 队列消息隐藏于主消息流，只在输入框上方的队列托盘显示（对齐 Multica Web 参考实现，语义清晰）。
- 本轮一次实现 P1+P2：运行中可发 + 队列显示 + 停止 + 立即发送/编辑/删除/清空。
- 编辑队列消息回填时追加到现有草稿，不覆盖用户已输入内容。
- 草稿恢复采用「本地即时回填 + 启用服务端 `chat-draft-restore-v1`」，兼顾即时性与跨设备/重连。
- 队列收敛逻辑移植为纯函数，避免每次事件整页 refresh 造成闪烁，同时保留 refresh 作为权威兜底。
- 服务端 409（任务已被领取）时队列编辑/删除退化为普通停止，避免操作静默失败。
