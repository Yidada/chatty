## 1. 消息呈现（用户气泡 / 助手全文）

### 1.1 结构与对齐（(a) 已验证，基于官方商店截图逐像素测量）

官方 iPhone 截图（1290×2796，机内营销框；实测**屏内区域 x=133..1156，宽 1024px**，即渲染倍率 1024/375pt ≈ 2.73，下文括号内为换算 pt）：

- **用户消息 = 右侧对齐的浅色气泡**，不是全宽。固定**右边距 52px（≈17pt）**；左边为可变（长消息时最长气泡 = 789px / 1024px ≈ 77% 屏宽），即**宽度随内容自适应，靠右停靠**。
  - `us4` 长问句气泡：x **326→1114**，宽 789px（≈289pt），高 325px（≈119pt）
  - `cn5` 短问句气泡：x **551→1104**，宽 554px（≈203pt），高 **128px**（≈47pt，3 行）
  - `us5` 短问句气泡：x **326→1104**，宽 779px，高 **128px**（2 行）
  - → **气泡高度在小尺寸下不随行数变化（均 128px ≈ 47pt），说明圆角为固定值而非胶囊形**。
- **助手回复 = 全宽无气泡纯文本**，直接铺在页面底色上，宽度 = 内容区（x 186→1104，左右各留 53px ≈ 19pt）；无背景、无边框、无头像。
- **助手正文分行间距**：CN5/US5 均为**行距 73px（≈26.7pt）**，与内容区满宽一致，证实不是气泡内文本。

### 1.2 颜色（(a) 已验证，官方截图直接取样，非猜测）

| 元素 | 浅色模式实测色值 |
|---|---|
| **用户气泡底色** | **`#EDF3FE`**（RGB 237,243,254）— 淡蓝紫，非纯灰 |
| 助手正文文字 | **`#0F0F0F`**（RGB 15,15,15） |
| 思考块正文/工具行说明文字 | **`#7D7F85`**（RGB 125,127,133）——灰色，比正文明显浅 |
| 页面/输入卡片 | `#FFFFFF` |
| 深色模式 | **(c) 未知 —— 官方商店截图只有浅色模式**；未能找到可信的深色模式色值 |

### 1.3 圆角、头像、时间戳、间距

- **圆角**：从 `cn5` 气泡上边缘测得直线段 x 588→1066（479px），全长 554px → 两端各切 ≈ 33px；按该像素↔pt 比例推 **半径约 12pt（±2pt）**，属"圆角矩形"而非胶囊/尖角。置信度：**(b) 像素推断**（抗锯齿边缘使精确值有 ±1–2px 误差）；**未能拿到官方设计规格数值**。
- **头像**：消息列表内**没有用户头像也没有助手头像**（商店截图中消息区完全无圆形头像）。空态只有一个品牌鲸鱼 Logo；思考块内的搜索结果行有第三方站点 favicon（Google/百度/Bing 等小圆标），属于工具结果装饰而非头像。置信度：**(a)**（截图内直接可见）。**未能验证**是否在设置里可开启头像。
- **时间戳**：所有官方截图中消息**均无时间戳**。**(c) 未知**（也未证伪）。
- **垂直间距**：上一轮助手正文末行 → 下一条用户气泡顶边 ≈ **60–62px（≈22pt）**；用户气泡底 → 思考块/正文顶 ≈ 70–90px（≈26–33pt）。气泡内文字左右内边距很小（文字左边界与气泡左边界几乎齐平）。置信度：**(a) 测量**，但"语义化的设计 token"未获官方确认。

### 1.4 2025（R1 时代） vs 2026（Instant/Expert 时代）

对比物：维基共享上 2025-02-09 的**真实机内截图**（拍摄设备 EXIF = `AMP-AN00`，华为机型 → **注意是鸿蒙/Android 版，非 iOS**）[File:DeepSeek界面截图.jpg](https://zh.wikipedia.org/wiki/File:DeepSeek%E7%95%8C%E9%9D%A2%E6%88%AA%E5%9B%BE.jpg)。

| 项 | 2025-02（R1 时代） | 2026-09（当前） |
|---|---|---|
| 空态文案 | `嗨！我是 DeepSeek` + `我可以帮你搜索、答疑、写作，请把你的任务交给我吧~` | `下午好，有什么可以帮到你？` / EN `How can I help you?` |
| 输入框占位符 | `给 DeepSeek 发送消息` | `发消息或按住说话` / EN `Type a message or hold to speak` |
| 输入框内模式控件 | 标签为 **`深度思考（R1）`**、**`联网搜索`**（纯文字胶囊 chip） | **`深度思考`**、**`智能搜索`**（带图标 chip）；EN `Think` / `Search` |
| 工具栏 | 左 `+`，右蓝色圆形上箭头发送按钮 | 输入卡片内：左 `⊕`（相机/相册/文件菜单）、右语音按钮；空态无独立发送圆钮 |
| 顶栏 | 左汉堡 `≡`、中 `新对话`、右 `⊕` | 左汉堡（带圆形底）、中会话标题、右 `⊕`（带圆形底） |
| 思考块 | 展开显示，配合搜索工具入口 | 实时工具轨迹 + 完成后**自动折叠** |

**结论**：消息呈现的"用户右对齐浅色气泡 + 助手全宽纯文本"这一基本范式在 R1 时代已存在；2026 年的变化主要发生在**顶栏/输入卡片/模式 chip/思考块折叠行为**，而不是气泡范式本身。置信度：**(a)**（两端各有截图），但中间年份的演进细节 **(c) 未知**。

## 2. 可折叠的"思考"块（本次调研最有价值的发现）

### 2.1 三态的确切文案（(a) 已验证，均来自官方商店截图）

| 状态 | 中文 | 英文 | 来源截图 |
|---|---|---|---|
| **流式思考中（展开）** | **`正在思考`** + 右向 chevron `>` | **`Thinking`** + 右向 chevron `>` | CN [截图3](https://is1-ssl.mzstatic.com/image/thumb/PurpleSource221/v4/89/44/83/89448396-3bcc-f43a-72cb-e4ecdd8fe208/3.png/1290x2796bb.png) / EN [截图3](https://is1-ssl.mzstatic.com/image/thumb/PurpleSource211/v4/a7/44/c1/a444c1d7-5e58-dc21-3b39-6d1541a92938/4.png/1290x2796bb.png) |
| **思考结束（折叠）** | **`已思考（用时 90 秒）`** + chevron `>` | **`Thought for 52 seconds`** + chevron `>` | CN [截图4](https://is1-ssl.mzstatic.com/image/thumb/PurpleSource211/v4/4d/43/11/4d4311ef-85e5-8741-dfbe-aaa1d89c2f32/4.png/1290x2796bb.png) / EN 同上 |
| 用户期望的写法「已深度思考（用时 N 秒）」 | **未能证实存在于当前 iOS 版** | — | **(c) 未知** |

**重要更正**：任务里假设的 `已深度思考（用时 12 秒）` **在官方 iOS 材料中找不到**；官方中文用的是 **`已思考（用时 90 秒）`**（无「深度」二字，全角括号，数字与「秒」之间**有空格**）。请勿直接照抄「已深度思考」到产品文案。

### 2.2 折叠后的排版与展开样式（(b) 截图像素推断）

- 折叠行**单行、无背景、无边框**，位于用户气泡之下、答案之上；文字色 `#0F0F0F`（黑色，与正文同色）；chevron 为同样黑色 `#0F0F0F` 的**右向尖括号**（`>`，非 v 形下箭头），紧贴文字右侧（`cn4` 中 chevron 墨迹位于 x≈920–950，文字约在 x 186–900）。
- 折叠行墨迹高度 42px（≈15pt），行内实际字号约 14–15pt；**chevron 紧邻文字，未做整行分隔**——即"点整行/点文字右侧箭头"都可作为展开热区，但**官方未文档化热区范围**，**(c) 未知**。
- 展开态（`cn3`/`us3`）：
  - 标题行中文为灰色 `#7D7F85`，英文为黑色 `#0F0F0F` → **中英文标题样式不一致**（可能是版本/状态差异，无法确认是设计意图还是历史遗留）。
  - 正文为**灰色 `#7D7F85`**，字号明显小于答案正文：实测行距 **62–63px（≈22.8pt）**，对照答案正文行距 73px（≈26.7pt）→ 思考正文约 **14–15pt**，答案正文约 **17pt**。行高倍数两者都≈1.43。
  - 结构上有**悬挂缩进的圆点列表**（`•` 在 x≈300，文字从 x≈348 起，第二行对齐 x≈348），部分工具行用图标+**黑色粗体**名称，其后说明为灰色。例：
    - `🔍 已搜索到 17 个网页` + 3 个 favicon（EN：`Found 17 web pages`）
    - `📄 已浏览 3 个页面` + favicon（EN：`Read 3 pages`）
    - `📄 查找关键词`（EN：`Found keyword`）
- **是否自动展开→自动折叠**：**已由官方更新说明证实**（中文「支持思考过程自动折叠」/ EN "Thinking process now collapses automatically"，见 §0）。截图亦佐证：`cn4` 已折叠且显示用时，`cn3` 思考中展开。**"是否在答案开始产出时立即折叠"这一精确时机 (c) 未知**。
- 思考中是否显示实时计时：**(c) 未知**（`cn3` 未显示 `用时`，只在结束后出现）。

### 2.3 长按 / 上下文菜单（此处证据最弱）

- **官方截图完全看不到助手消息下方的操作行**（复制/重新生成/点赞/点踩/分享）——因为截图中答案都被底部输入框裁切。→ **无法用官方材料证实该操作行的存在或图标排布**。
- 唯一硬证据来自 **App Store 中国区真实用户评论**（[CN 评论页](https://apps.apple.com/cn/app/6737597349?see-all=reviews&platform=iphone)）：
  - 2025-05-29 评论：「我会为我自己的人设/角色设定（PA）向 AI 提问，并反复点击「**修改**」按钮」，「**单条消息最多修改 7 次**」，「增加一个「**再试一次**」按钮，它同样让 AI 重新生成」 → 证实存在 **`修改`（编辑/重新生成）** 与 **`再试一次`** 概念。
  - 2026-06-15 / 06-13 / 06-18 多条评论提到「提问限制…**六次**」「回答的次数只能是**四次**」。
  - 2026-04-30 评论明确请求「**长按或悬浮菜单，增加「引用」按钮**」「选择文本片段后一键引用」→ 反证**当时没有"引用/部分引用"和"聊天记录全文搜索"**。
- **仍未证实（(c) 未知）**：`复制`、`重新生成`、`分享`、`删除`、`选择文本`、`分支(branch)` 在 iOS 上分别以什么形式存在（长按菜单？气泡下方图标行？），以及点赞/点踩是否存在于 iOS。
- **第三方反向工程线索（仅作方向，勿当证据）**：DeepSeek 网页版的「默认折叠思考」社区脚本描述思考块的两种折叠模式（`始终折叠` / `思考结束后折叠`），说明官方实现里折叠是可被脚本 hooks 的：[Greasy Fork 580006](https://greasyfork.org/en/scripts/580006)（发布日期 2026-05-27，**针对 deepseek.com 网页版，非 iOS**）。

## 6. 给 iOS 复刻团队的落地建议（基于已验证项）

- 气泡：**右对齐、宽度随内容收缩、底色 `#EDF3FE`、固定圆角 ≈12pt、右边距 ≈17pt、最大宽度控制（实测最长 ≈77% 屏宽，建议按"留出左对齐余量"处理）**。
- 助手：**不要做气泡**，全宽纯文本，正文色 `#0F0F0F`，行距 ≈1.43 倍。
- 思考块：灰色 `#7D7F85` 正文 + 圆点/图标工具行 + 完成态单行 `已思考（用时 N 秒）` / `Thought for N seconds` + 右向 chevron；并在答案开始时自动折叠（官方已确认此行为）。
- 需要自行定夺的部分（无官方依据）：操作行图标、停止按钮、滚动按钮、深色模式配色 —— 建议**按 iOS HIG 自行设计，并在报告中标注为"自研决策"而非"复刻"**。
