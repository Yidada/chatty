# iOS：Mika 对话输入框回车改为直接发送

Benjamin 的小优化（2026-09-13）：输入框里的回车原本插入换行，改成直接发送——软键盘回车键就是「发送」，按下即发出，不必再点右侧 ↑ 按钮。

交付行为：

1. 软键盘回车键是系统 send 键，按下直接发送当前草稿；换行符不进入草稿。
2. 中文输入法组词中的回车只上屏候选词，不发送。
3. 空草稿、或 `!canSend`（发送中、无可用 Agent、无权限、会话已归档）时回车无副作用，也不清空草稿。
4. 附件、项目选择、排队与「立即发送」、停止、`⌘↵`、`⌘F` 聚焦输入框、发送后保持键盘（CLE-97）等既有路径零回归。
5. 多行草稿的展示能力保留：粘贴 / 冷启动恢复 / 事项上下文草稿仍按 `lineLimit(1...6)` 增长到六行后框内滚动；手打换行只保留硬件键盘 `⇧↵`。

现状证据：`ios/Chatty/ChatScreen.swift` 的 `TextField(..., axis: .vertical).lineLimit(1...6)` 只能靠 `chat.send` 按钮发送；竖排 `TextField` 的回车走「插入换行」，既不回调 `onSubmit` 也不接受 `.submitLabel(.send)`。

范围：只改输入区这一处（含受影响的回放脚本与文档）。不动发送 / 附件 / 项目选择语义，不动版本号，不上传 TestFlight（`0.2.0` 打包归 CLE-98）。
